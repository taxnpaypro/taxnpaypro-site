은행 CSV·QFX를 QuickBooks Desktop QBO·IIF 파일로

은행이 QBO 파일을 주지 않거나 받은 파일이 가져와지지 않을 때 쓰세요. 가져오기 전에 명세서 잔액과 맞는지 먼저 확인합니다.

  • 파일이 전송되지 않음. 브라우저 안에서만 처리
  • 다시 가져와도 중복 없음 (고유 ID)
  • 수표 번호로 장부와 자동 매칭
  • 대조 전에 잔액 미리 확인

사용 순서

  1. 은행에서 내려받기거래내역을 CSV나 Excel로 받습니다. 명세서 기간과 같게 받으면 대조가 쉽습니다.
  2. 변환기에 올리기주요 은행 8곳은 열과 부호를 자동으로 맞춥니다. 틀린 곳만 고치면 됩니다.
  3. 잔액 확인명세서의 기초·기말 잔액을 넣으면 가져오기 전에 일치하는지 바로 보여 줍니다.
  4. QuickBooks Desktop에서 가져오기백업 후 .qbo는 Banking › Bank Feeds › Import Web Connect File, .iif는 File › Utilities › Import에서 엽니다.

QBO와 IIF, 무엇을 고를까

QBO (Web Connect)

  • Bank Feeds가 작동하는 버전용
  • 이미 입력한 수표·입금과 자동 매칭
  • 다시 가져와도 중복 없음

IIF

  • Web Connect가 막힌 구버전용
  • 계좌 장부에 바로 기록
  • 중복 방지가 없어 한 번만 가져오기

자주 묻는 질문

은행 정보가 인터넷으로 전송되나요?

아닙니다. 파일은 브라우저 안에서만 읽고 변환하며 서버로 올라가지 않습니다.

신용카드와 QFX 파일도 되나요?

네. 계좌 종류에서 Credit Card를 고르세요. 가져오기에 실패한 QFX·OFX·QBO 파일도 원래 거래 ID를 유지한 채 다시 만듭니다.

QuickBooks Online에도 필요한가요?

아닙니다. QuickBooks Online은 CSV를 바로 올릴 수 있습니다. 이 도구는 QuickBooks Desktop용입니다.

무료인가요?

네, 무료입니다. 가져오기 전에는 꼭 회사 파일을 백업하세요.
